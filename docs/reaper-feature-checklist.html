Reaper — Feature & Functions Checklist

Boring, simple, comprehensive inventory. Check items as needed for demos, QA, or onboarding.

Product version: v0.4.82 · Roles: Member · Manager · Admin · Platform admin

1. Access & accounts

  • Log in with email/password
  • Sign up / create workspace (when platform allows)
  • Forgot password / password reset
  • Set password after invite or recovery link
  • Log out
  • Change password (Settings)
  • Upload / change profile photo
  • Demo mode login (no backend)
  • Switch demo profile (demo mode)
  • Invite a person to the workspace (Manager+)
  • Change a user’s role: member / manager / admin (Admin)
  • Platform admin console: list workspaces (Platform)
  • Platform: rename / disable / delete workspace (Platform)
  • Platform: enter a workspace (Platform)
  • Platform: toggle “allow workspace signup” (Platform)
  • Disabled workspace blocks normal use

2. Workspace settings

  • Open Settings
  • Edit organization name (Admin)
  • Edit organization URL / slug (Admin)
  • Choose theme (light / dark)
  • Choose default start page
  • Choose schedule time offset / page width preferences
  • Install as desktop app (PWA)
  • Dismiss / snooze install prompt
  • Re-open install tip from Settings
  • Enable / disable org public share link (Manager+)
  • Regenerate org public share link (Manager+)
  • Create / edit holiday calendars (Manager+)
  • Apply holiday calendar to people (Manager+)
  • Load demo data (Manager+ / demo)

3. Navigation & shell

  • Dashboard nav item
  • Schedule nav item
  • Projects nav item
  • My Tasks nav item (Member only)
  • Reports nav item (Manager+)
  • Clients nav item (Manager+)
  • People nav item (Manager+)
  • Member cannot open Clients / People / Templates / full Reports
  • Favorite project tabs in nav
  • Reorder favorite project tabs
  • Breadcrumbs / page headers
  • About Reaper dialog
  • Account menu
  • Version refresh banner when a new deploy is available
  • Auto-reload when tab is hidden and a new version exists

4. Dashboard

  • Identity / “who am I” card
  • View As person (Manager+)
  • Clear View As
  • Bulletins list
  • Create bulletin
  • Edit bulletin
  • Delete bulletin
  • Pin bulletin
  • Bulletin audience: all users
  • Bulletin audience: selected people
  • Bulletin audience: selected pods
  • Bulletin audience: pods + people combined
  • Unread bulletin indicator
  • Dismiss / mark bulletin read
  • Member only sees bulletins in their audience
  • Tagged / @mention comments panel
  • Dismiss mention
  • Overdue / urgent / high-priority tasks
  • Utilization / capacity summary widgets
  • Project health / at-risk budgets (Manager+)
  • Upcoming leave / leave calendar widget
  • Unread badge on Dashboard in nav

5. Schedule

  • View schedule grid
  • Zoom: day / week / month (as supported)
  • Scroll / navigate date range
  • Create assignment
  • Edit assignment hours / dates / status
  • Delete assignment
  • Drag move assignment
  • Resize assignment
  • Weekly recurrence
  • Recurrence end date
  • Exception weeks / skip occurrence
  • Split this occurrence vs future
  • Tentative vs confirmed status (as supported)
  • Overlap / occupancy handling
  • Leave shown on schedule
  • Filter by pod
  • Member sees own row only
  • Manager sees all people (scoped as configured)
  • Hide people marked hide-from-schedule
  • Project manager schedule indicators (when multiple PMs)

6. Clients (Manager+)

  • List clients
  • Create client
  • Edit client name / color / notes
  • Edit client contact fields
  • Archive / restore client
  • Delete client
  • Create project from client
  • Hide client from public share
  • Search / filter clients (page UI)

7. Projects

  • List projects
  • Filter / sort projects
  • Create project
  • Edit project fields (name, color, status, dates, etc.)
  • Set budget mode (fixed / hourly / monthly retainer, as supported)
  • Set project manager
  • Archive / unarchive project
  • Delete project
  • Member only lists projects they can open (roster, PM, schedule, or assignee)
  • Open project hub (pretty URL with client + project slug)
  • Legacy project UUID URL redirects
  • Star / unstar project favorite
  • Set project team roster (project members)
  • Assign tasks to roster people
  • Milestones: create / edit / delete / reorder
  • Task lists: create / rename / color / archive
  • Tasks: create / edit / delete
  • Tasks: parent / child hierarchy
  • Tasks: set status
  • Tasks: set assignee
  • Tasks: set start / due dates
  • Tasks: notes
  • Member can update task status on accessible projects
  • Task comments / rich notes
  • @mention people in comments
  • Edit own comment
  • Delete own comment (or manager delete)
  • Comment reactions
  • Project notebook / assets: add link or file entry
  • Edit / delete asset
  • Hide asset from client portal
  • Budget card on project
  • Progress indicators (calendar / tasks / milestones)
  • Enable / disable client portal link for project
  • Hide project from org public share
  • Apply project template
  • Export project as template
  • Project Manager can edit their project without full org-manage role

8. My Tasks / Tasks report

  • My Tasks page for members
  • Tasks report for managers
  • Overdue tasks list
  • Undated tasks list
  • Completed tasks list
  • Filter by client / project (as supported)
  • Open task deep link into project

9. Reports (Manager+)

  • Reports hub
  • Utilization report (people × weeks heatmap)
  • Budgets report (org-wide burn)
  • Per-project budget detail page
  • Budget health states (healthy / near / over)
  • Forecast data (where exposed)

10. People (Manager+)

  • List people
  • Create person
  • Edit person (name, role title, office, email, etc.)
  • Set cost / bill rates
  • Set capacity / hours
  • Upload person avatar
  • Hide person from schedule
  • Delete person
  • Link person to invited profile
  • Create / edit / delete pods
  • Set pod manager
  • Add / remove pod members
  • Assign person to multiple pods
  • Create leave (full day / partial)
  • Edit / delete leave
  • Leave blocks / multi-day leave
  • Leave override of schedule assignments (as supported)

11. Templates (Manager+)

  • List templates
  • Create template
  • Edit template name / description
  • Delete template
  • Template milestones
  • Template task lists
  • Template tasks
  • Apply template to a project
  • Export live project to template
  • Member cannot open Templates

12. Search

  • Open search (Cmd/Ctrl+K or UI trigger)
  • Search clients
  • Search projects
  • Search tasks
  • Search comments
  • Client match also lists that client’s projects
  • Navigate to result
  • Manager/admin: org-wide results
  • Member: only accessible projects (and related clients/tasks/comments)
  • Minimum 2 characters

13. Notifications

  • In-app unread bulletins
  • In-app unread @mentions
  • Desktop notification for mention (when permitted)
  • Desktop notification for bulletin (when permitted)
  • Browser / OS permission prompt
  • Click notification opens relevant place (e.g. Dashboard)

14. Sharing — org public board

  • Open public board via token URL
  • Read-only: Dashboard
  • Read-only: Schedule
  • Read-only: Projects (and project pages)
  • Read-only: Reports
  • Read-only: Clients
  • Read-only: People
  • Templates blocked / redirected on share
  • Hidden clients omitted
  • Hidden projects omitted
  • Sensitive fields stripped (profiles, rates, etc.)
  • Share chrome labeled public / read only

15. Sharing — client project portal

  • Open portal via project token URL
  • Show project progress / team / selected assets
  • Hide notebook items marked hidden from portal
  • Do not expose other clients’ work
  • Do not expose internal-only costs / secrets (sanitized)

16. Permissions summary

  • Member: self schedule; accessible projects; My Tasks; limited settings
  • Manager: full manage surfaces; View As; sharing; holidays; templates
  • Admin: manager + org rename/slug + role changes
  • Project Manager on a project: can edit that project without org-manage
  • View As does not grant Settings as the viewed person
  • Search respects member project access
  • Bulletin audience enforced for members

17. Data domains covered (reference)

Not separate UI screens — capabilities implied by the product.

  • Organizations / workspaces
  • Profiles & roles
  • Clients
  • Projects & project members
  • Milestones
  • Task lists & tasks
  • Task comments, mentions, reactions
  • Project assets / notebook
  • Assignments & recurrence
  • Leave & holiday calendars
  • People & avatars
  • Pods & pod members
  • Bulletins & unread inboxes
  • Project favorites
  • Project templates
  • Budgets / utilization aggregates
  • Public share tokens (org + project)
